| 정상 영상 불필요 후보 | 10/34 | 11/34 |

## Gemma 프롬프트 비교

완료. 전체 영상 84회 + 기존 YOLO 호출 대상 39회 = 123회 실제 응답을 받았다.
요청 실패·형식 오류는 없었다. 형식이 맞는다는 것이 판단이 맞는다는 뜻은 아니다.

같은 Gemma 4 12B 가중치·옵션·스키마·RGB 프레임·사용자 문구를 유지한다.
system 문구에만 정상 판정에 관찰 근거가 필요하다는 설명을 추가했다.
단독 84개 및 기존 YOLO 호출 대상 39개를 실제로 다시 호출한다.
위 후보 변경은 이 비교에 섞지 않는다. 무료 로컬 Ollama만 사용한다.
각 요청의 A 입력을 원본에서 재구성하고 해시 일치를 검사한 다음 B를 전송한다.
이 비교의 요청 시간은 실시간 낙상 감지 지연이 아니다.

### 어떤 판단이 바뀌었나

- 단독에서 413·V002·V019가 낙상에서 정상으로 바뀌었다.
- YOLO 후에는 307·33(ltx)·V019·V049가 낙상에서 정상으로 바뀌었다.
- 단독 V023·V027·V031은 정상에서 의심으로 바뀌었다. 그러나 다른 의심 영상이
  정상으로 바뀌어 의심을 정상으로 놓친 전체 건수는 17개로 같았다.
- 단독 414는 수정 후에도 '움직임이 정적이고 낙상 과정이 보이지 않는다'는 이유로
  정상이라고 답했다. V004도 바닥의 성인을 어린아이로 해석하고 휴식·놀이로 추정했다.
- V002·V019 등에서는 같은 프레임을 보고 기존에는 균형 상실로 설명했지만,
  수정 후에는 스스로 몸을 낮춘 것으로 설명했다. 답변 설명이 실제 의도의 증거는 아니다.

이 결과는 '정상 판단에 근거가 필요하다'는 문구를 덧붙이는 것만으로는 부족하다는

Gemma 전체나 다른 프롬프트·모델의 성능 한계로 일반화하지 않는다.

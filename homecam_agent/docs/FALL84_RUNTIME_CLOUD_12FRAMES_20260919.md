- 마지막 최대 10초에서 시간순 RGB 12장, 640×400, 원본 비율 유지·검정 여백·잘라내기 없음.
- 실제 원본은 640×400 41개 / 1280×720 43개. 원본 파일은 보존했다.

  **이번 결과는 약 5초에서 12장을 고른 성능이며, 10초 전체 입력 성능은 아직 모른다.**

  정답·YOLO·센서·소리·Agent 답변은 보내지 않았다.
- 요청 제한 20초, temperature=0, num_predict=512, thinking=false.
- 호출마다 Free 계정을 확인했다. 결제·충전 설정 변경 및 한도·인증 오류는 없었다.

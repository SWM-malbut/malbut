# Gemma 좌표 프롬프트 v3 — 9개 실제 호출 결과

SWM25-186 / 2026-09-26

**Gemma에만 9개를 호출했다. 이번 프롬프트는 운영에 반영하지 않는다.**
좌표 오류가 일부 줄었지만 JSON을 두 번 반환하는 오류가 생겨,
라벨과 응답 검사를 모두 통과한 정답 수는 이전과 같은 5/9개였다.

## 조건

- 사용 모델: Ollama 직접 Cloud API `gemma4:31b`. Gemini 호출 없음.
- [준비한 진단용 9개](VLM_BOX_PROMPT_V3_20260926.md), `normalized_boxes_v3`.
- 같은 영상의 최근 5초, RGB JPEG 12장, 640×400. 정답·센서·음성·YOLO 결과 미전송.
- 기존 `low_reasoning` 프로필 유지. Gemma 요청은 `think=false`, temperature 0,
  `num_predict=2048`. 실제 요청 본문에서 시스템 지시문 외 항목이 같음을 확인했다.
- 요청당 최대 20초, 자동 재시도 없음. 시간 초과 시 다음 영상으로 진행하도록 설정했지만
  이번에는 시간 초과가 없었다.
- 사용자 요청: “일단gemma로 테스트해봐”. 이번 9회에만 실행부 한도 $0.10,
  요청당 예약 $0.01을 설정했다. 이는 공급자 청구 상한이 아니다.

기존 결과의 일부를 재사용한 것이 아니라 새 요청 9회를 보냈다. 비교 열의 이전 수치는
84개 평가 중 같은 9개의 결과이며, 원본 응답과 기존 점수는 변경하지 않았다.

‘낙상 의심’으로 읽히지만, 프로그램이 요구한 하나의 JSON으로 반환하지 않아
라벨을 채택할 수 없었다. 기존 검사 기준에 따라 정답에서 제외했다.

읽을 수 있는 새 응답 7건 중 `regions: []`인 의심 발견 항목은 없었다.
형식 오류 2건의 위치 목록 집계는 확인 불가로 남겼으며 0으로 채우지 않았다.
정상 영상 SYN022의 `findings: []`는 위치를 못 준 의심 응답과 구분한다.

중앙값에는 좌표·JSON 오류가 있어도 HTTP 응답 전체를 받은 9건을 모두 포함했다.
비용은 응답 사용량에 [Ollama 공식 단가](https://ollama.com/pricing)를 적용한 추정치다.
2026-09-26 재확인: 100만 토큰당 입력 $0.14, 캐시 입력 $0.05, 출력 $0.40.
9건 모두 사용량을 받았고 미확인 비용은 없다. 최종 청구서 금액을 확인한 것은 아니다.

## 판단과 남은 확인

- 이 시험에서는 좌표 확인 문장을 추가하는 것만으로 안정적인 출력이 되지 않았다.
  기존에 통과했던 사례에서 새 오류도 생겼으므로 v3를 운영에 적용하지 않는다.
- 실패 유형을 골라 만든 9개이며, 프롬프트별로 한 번씩 서로 다른 실행에서 받은
  응답이다. 전체 84개 정확도나 프롬프트 변경만의 효과를 입증한 결과가 아니다.
- 이번 ‘검사 통과’는 숫자·형식 검사다. 실제 사람 위치의 정확도와 사건 연결
  성공률을 측정한 것은 아니다.
- 다음 실험은 별도로 결정한다. 다른 모델 호출이나 추가 재시도는 하지 않았다.

# 관절값 흔들림 대응: 구현과 84개 비교

## 요약

관절값이 달라질 때 이전 자세를 즉시 버리는 문제를 대상으로 두 가지를 따로 비교했다.
첫 방식은 추가 후보가 없었다. 두 번째 방식은 **V034(낙상 의심) 한 개를 새로 요청**했고,
이번 84개에서 정상의 추가 요청이나 기존 요청 손실은 없었다.

이는 같은 합성 개발 데이터에서 발견한 작은 개선이다. 낙상 자체를 더 정확히 분류했다는
의미가 아니다. 후속으로 V034를 Gemma에 실제 호출했으나 정상으로 판정해 최종 확인 대상
인식률은 개선되지 않았다(아래 후속 검증). 운영 기본값은 바꾸지 않았다.

## 구현한 방식

### A. 잠깐 흔들린 뒤 낮은 자세로 돌아오는 경우

`experimental_pose_stability.py`

- 같은 사람의 실제 usable Pose에서 낮은 자세 기록을 유지한다.
- 몸 전체의 넓은 배치는 남아 있지만 낮은 자세 조건과 불일치하는 프레임을 최대 1개 보존한다.
- 해당 프레임과 그 앞뒤 간격은 낮은 자세 관측 시간에 더하지 않는다.
- 실제 낮은 자세로 돌아왔을 때만 요청할 수 있다. 실제 관측 간격 합 0.6초 조건은 그대로다.
- 모호한 연결, 부족한 관절, 미검출, 다른 자세, anchor 변경 등은 이어 붙이지 않는다.

결과: 추가 후보 0개. V034는 불일치가 여러 프레임 이어져 낮은 자세로 빨리 돌아오지 않았다.
이 결과를 보존하고 다음 방식은 별도 프로토콜로 등록했다. 첫 방식의 수치를 다시 조정하지 않았다.

### B. 낮은 자세를 본 뒤 관측 불일치가 이어지는 경우

`experimental_pose_disagreement.py`

- 같은 사람의 실제 낮은 자세가 연속 3표본 이상, 0.4초 이상 관측되어 있어야 한다.
- 마지막 낮은 자세 후 0.5초 이내에 실제 기하 불일치가 2표본 이어지면 확인을 요청한다.
- 불일치 프레임도 충분한 관절, 넓은 박스·관절 배치가 있어야 한다. 박스만으로 요청하지 않는다.
- 3표본/0.4초/2표본/0.5초 구성은 기존 pose-loss의 약한 확인 요청 조건에서 가져왔다.
- 이전 낮은 자세와 현재 불일치를 분리해 남긴다. 현재도 누웠다고 확정하지 않는다.
- 현재 Pose가 있으므로 missing이라고 기록하지 않는다. 현재 관측 ID와 실제 이전 표본을 보존한다.
- 종류는 `found_down` 확인 후보이며, 사용자 라벨 '낙상' 확정이나 보호자 알림이 아니다.
- 기존 요청 중복 억제를 그대로 적용한다. 기존 후보는 요청 또는 원문 증거 업데이트로 보존한다.

실험 실행은 `replay_pose_stability.py`의 `--disagreement-request`로 구분한다.
이 옵션이 없으면 A 방식이며, `--control`은 추가 분기를 끈 대조군이다.
두 방식을 동시에 적용하지 않았다. 모델·신뢰도·추적·기존 후보 조건·라벨·박스는 동일하다.

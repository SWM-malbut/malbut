- 모든 영상과 세 라벨에 공통 적용한다. V020·V021만을 위한 점수 예외가 아니다.
- 기계용 개정 기록: `evaluations/synthetic_fall_v1/scoring_criteria_v2_r1.json`.

## 판단 근거

‘느리면 정상’, ‘침구가 없으면 낙상’처럼 단서 하나를 자동 판정 규칙으로 쓰지 않는다.
다만 사람이 영상의 보이는 동작을 판단할 때, 반드시 두 개 이상의 단서가 있어야 하는 것은 아니다.
근거가 제한적이면 그 한계를 함께 적는다. 이것만으로 라벨을 자동 변경하지 않는다.
메모가 없는 다른 영상을 모두 근거가 확실한 영상으로 간주하지도 않는다.

V020·V021은 기존 정상 행동 라벨을 유지한다. 합의한 보충 이유는 다음과 같다.

> 뒤로 눕는 과정이 보이며, 내려가는 속도가 정상적으로 눕는 동작에 가깝다고 판단함.
> 따라서 정상으로 분류함. 다만, 속도 외에 이를 뒷받침할 단서는 부족함.

원래 이유와 사용자 추가 설명은 보존한다. 이번 합의는 영상 재생이나 모델 답변으로 새로 판정한 것이 아니다.

## 모든 영상에 같은 채점 적용

- 유효한 예측 라벨이 정답과 같으면 1점, 다르면 0점이다. 실패 처리와 분모는 기존 기준을 유지한다.
- 근거가 제한적이라는 메모 때문에 점수를 더 주거나, 평가에서 제외하거나, 분모를 줄이지 않는다.
- 정상 정답에 낙상·낙상 의심으로 답하면 분류 오답이며, 확인 대상 채점에서는 불필요한 확인이다.
- 설명에 타당한 점이 있어도 분류 부분 점수를 주지 않는다. 판단 이유 검토는 별도로 한다.
- 모델 결과에 맞춰 정답이나 근거 메모를 유리하게 바꾸지 않는다.

## 기록과 보고서

평가용 정답 항목에 선택적으로 `judgment_evidence_limited`와 `judgment_note`를 둔다.
전자는 근거가 제한적이라고 사람이 확인한 표시이며, 후자는 그 이유다.
표시는 새 라벨이나 수치 신뢰도가 아니다. `true`이면 비어 있지 않은 이유를 요구한다.
모든 라벨에 사용할 수 있고, 이 두 필드는 채점 후 설명에만 사용하며 모델 입력에 보내지 않는다.

공통 보고서는 해당 메모를 예측·정답·정오 여부와 함께 표시한다. V020·V021의 ID를 채점 코드에 넣지 않는다.
새 실행은 기존 기준과 이번 개정 기록의 해시, 개정된 프롬프트 해시를 함께 남긴다.
과거 실행 결과는 변경하지 않는다.

9개 확인 질문과 기준 적용 논의는 끝났다. 총 77개(낙상 18·의심 25·정상 34)는 그대로다.
새 추론 입력 목록·영상 해시·실행 조건을 고정하는 작업과 실제 모델 재평가는 아직 하지 않았다.
새 입력 목록을 만들 때 보충 기록의 두 필드를 해당 정답 항목에 옮기고 해시로 고정해야 한다.

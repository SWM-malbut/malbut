## 공통 대상 ID 연결 조건

SAM은 영상 속 영역을 추적할 뿐, Pose ID나 사건 ID를 자동으로 연결해 주지 않는다.
이번에 별도 실험 코드로 다음 연결 규칙을 추가했다.

1. SAM 박스와 실제로 관측한 Pose 박스의 IoU가 0.60 이상이고, 다음 후보보다 0.15 이상 높음.
   약한 관측이나 아직 ID를 못 붙인 사람 박스도 경쟁 후보에서 빼지 않음.
2. Pose의 `associationUsable`이 참이고 현재 관측 구간의 연결 토큰이 있어야 함.
3. 같은 Pose ID·토큰이 연속 3회 이상, 0.5초 이상 일치해야 연결함. 이전 시점까지 소급하지 않음.
4. Pose 관측 누락·약화·애매한 겹침이 발생하면 현재 연결을 해제함.
   Pose ID나 연결 토큰이 바뀌면 다시 연속 관측을 확인함.
5. SAM 마스크가 없어지거나 시각 간격이 0.5초를 넘으면 영상 구간을 끊음.
   전후 박스 IoU 0.20 미만 또는 면적비 3배 초과도 같은 구간으로 유지하지 않음.

위 수치는 결과를 채점하기 전에 고정했고 이번 자료에 맞춰 낮추지 않았다.
SAM 영상 구간에 실험용 공통 ID를 붙이고, 조건이 맞는 동안만 Pose ID를 연결했다.
이 ID는 사람의 실명이나 영구 신원, 사건 ID가 아니다. 여러 시점에 같은 사람이 있었다는
기하적 가설이며, 완전 가림이나 사람 교차 중 ID가 바뀌지 않는다는 보장은 없다.

한 장면의 Cloud 발견 하나만 처리하는 실험이다. 여러 발견이 있으면 하나를 임의로 고르는
대신 실행을 거절하도록 했다. 여러 SAM 대상과 여러 Pose 대상의 동시 일대일 배정은 미구현이다.

### 추적하지 않는 경우와 같은 연결 규칙으로 비교

실행했다. 이동 장면에서는 고정 박스 조건이 연결된 시점 0/29, SAM 조건이 17/29였다.

이 대조군은 **영상 추적 자체의 효과를 보기 위한 고정 박스**다. 기존 운영의 전체 Cloud 박스
대조 방식이나 이전 사건 병합 1/7과 같지 않으므로, 기존 병합률이 1/7에서 18/41로 개선됐다고
비교하면 안 된다.

# 84개 저장 응답의 실제 박스 위치 점검

SWM25-186 / 2026-09-26

**숫자 형식이 맞아도 사람의 머리·팔다리를 놓치는 박스가 남아 있었다.**
Gemma·Gemini의 저장 응답을 84개씩 확인했고, 정답 박스와 같은 프레임에서 수치 비교가
가능한 것은 각각 8개·14개 박스였다. 나머지 박스를 틀렸다고 세거나, 전체 위치 검증을
통과했다고 처리하지 않았다. 추가 API 호출·비용은 없다.

## 사용한 자료와 비교 방법

- 모델 응답: [공식 좌표 형식 v4로 재평가한 84개씩](FALL84_NATIVE_BOX_REEVALUATION_20260926.md).
  모델을 다시 호출하지 않고 원본 응답과 고정 변환 결과를 사용했다.
- 정답 박스: 9월 17일 사용자가 검수 완료한 동결 자료의 533개 박스.
  `fall84-user-boxes-yolo-20260917.9UdJDF/spatial-final/`의 승인 기록과 해시를 확인했다.
- 입력의 영상 해시와 정답 자료의 영상 해시, 라벨, 프레임 번호·촬영 시각을 대조했다.
  응답의 `frame_index`는 전송한 12장 안의 번호이므로 원본 영상의 프레임 번호로 연결했다.
- 원본 640×400은 그대로, 1280×720은 입력 생성 때와 같이 640×360으로 줄이고 위아래
  20픽셀 여백을 반영했다. 예측 박스와 정답 박스 모두 같은 640×400 캔버스에서 비교했다.
- 정답 박스는 **프레임 번호가 정확히 같을 때만** 사용했다. 가까운 프레임에서 가져오거나,
  이전 박스를 복사하거나, 중간 위치를 추측하지 않았다.
- 사람 연결의 수치 기준은 기존 동결 자료의 기준을 그대로 사용했다. 정답 박스 면적의
  50% 이상, 예측 박스 면적의 25% 이상이 겹치고 정답 박스 중심이 예측 박스 안에 있어야 한다.
  한 사람·한 예측이 서로 가장 잘 대응해야 하며, 여러 후보의 차이가 작으면 연결을 보류한다.
  이는 이번 **오프라인 대조 기준**으로, 실제 YOLO 추적 ID와의 사건 연결 시험은 아니다.
- 박스 겹침 정도인 IoU도 별도로 계산했다. 1이면 두 사각형이 같고 0이면 겹치지 않는다.
  면적 비율은 사각형 기준이며 실제 신체 픽셀의 비율이 아니다.

## 자동 대조 결과

| 항목 | Gemma | Gemini |
|---|---:|---:|
| 확인한 응답 | 84개 | 84개 |
| 프로그램이 읽을 수 있는 응답 | 83개 | 84개 |
| 반환한 유효 박스 | 185개 | 206개 |
| 같은 프레임의 정답 박스와 비교 가능 | 8개 / 8개 영상 | 14개 / 14개 영상 |
| 그중 기존 기준으로 대상 사람과 대응 | 8개 | 14개 |
| 그중 대상 정답 박스와 IoU 0.5 이상 | 8개 | 14개 |

이 표는 위치 정확도 100%라는 뜻이 아니다. Cloud에 보낸 12장과 기존 정답 박스의 검수
프레임이 많이 달랐고, 모델은 그중 2~4장에만 박스를 반환했다. 정답이 있는 프레임에
박스를 반환하지 않았다는 이유로 검출 실패로 세지 않았다. 정상 응답이 `findings: []`인
것도 명세에 맞는 동작이며 위치 검출 성공이나 실패로 세지 않았다.

두 모델 모두 예측 박스를 반환했고 정답 박스도 있는 **공통 비교 프레임은 5개**였다.

|---|---:|---:|---:|
| 307 / SYN004 | 24 | 0.862 | 0.885 |
| 33 LTX / SYN006 | 12 | 0.893 | 0.912 |
| 411 / SYN009 | 24 | 0.600 | 0.923 |
| 422 / SYN014 | 24 | 0.878 | 0.941 |

이 5개에서는 Gemini의 겹침 정도가 더 높았다. 그러나 적은 수의 선택된 프레임이므로
Gemini의 전체 위치 정확도가 더 높다는 결론이나 모델 교체 근거로 사용하지 않는다.
서로 다른 8개·14개를 그대로 같은 조건의 모델 점수로 비교하지도 않는다.

## 중복 JSON과 대상 연결 검증 범위

저장된 응답 168개를 기존 검사로 다시 읽고 이전 채점 기록과 같은지 확인했다.
Gemma SYN045는 `invalid_response / invalid_json`, 판단 값과 변환 응답은 `None`이었다.
정상으로 바꾸거나 마지막 JSON만 선택하지 않았으며 새 API 요청도 하지 않았다.
이 오류가 다시 발생하지 않도록 해결한 시험은 아니다.

이번 정답 자료로는 한 발견의 여러 예측 프레임 중 두 프레임 이상에서 같은 사람인지
확인할 수 있는 경우가 없었다. Gemma 발견 55건, Gemini 발견 53건 모두 연속 대상
검증에 필요한 정확한 프레임의 정답 자료가 부족했다.
따라서 **대상 바뀜이 0건이었다고 보고하지 않는다.** 실제 YOLO 추적·사건 병합도 아직 검증하지 않았다.

추가한 코드는 오프라인 검사와 테스트뿐이다. 운영 코드·기존 라벨·모델 응답은 수정하지 않았다.
비교 프레임이 없을 때 보류하는지, 여백 변환, 다른 사람·겹친 사람 처리, 잘못된 JSON을

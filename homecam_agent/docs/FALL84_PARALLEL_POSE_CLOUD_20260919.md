# YOLO-Pose + Cloud 5초·12장 독립 경로 재생 테스트

2026-09-19 완료. **기존 독립 실측 출력을 84개 영상별로 합쳐 새로 재생·채점**했다.
새 YOLO 추론·Cloud 호출은 0회다. 실제 두 모델의 동시 실행이나 실물 알림 시험은 아니다.

## 비교한 방법

- YOLO: `YOLO26s-Pose + 원본 비율 유지 + 추가 판단 조건`의 보존된 결과.
  52개 영상에서 원래 요청 53건. 108 중복도 원문대로 남겼다.
- Cloud: 9월 19일 실제 호출한 Gemma4 31B Cloud 84건.
  영상당 약 5초·RGB 12장·640×400, YOLO 결과 없이 장면 전체를 판정했다.
- 데이터: 사용자가 확정한 합성 영상 84개, 낙상 25 / 낙상 의심 25 / 정상 34.
  최신 검수 박스·시각을 보존하고 같은 영상 해시를 확인했다.
- 합치는 규칙: **YOLO 요청이 있거나 Cloud가 낙상/의심이면 해당 영상을 확인 대상으로 남긴다.**
  둘 다 있어도 영상 수는 한 번만 센다. Cloud 정상 판정이 YOLO 요청을 취소하지 않는다.
- Cloud 실패·시간 초과·판단 불가는 정상으로 바꾸지 않는다. YOLO 요청이 있으면 유지하고,
  없으면 미판정으로 남긴다. 실제 이번 Cloud 결과에는 실패가 없었다.
- 정답·대상자 검수 결과는 합치는 규칙에 넣지 않고 결과를 만든 뒤 채점에만 사용했다.

## 1. 원래 요청과 영상 단위 확인 대상

이 표는 **확인이 필요한 영상을 골랐는가**를 센다. 낙상 확정 정확도나 보호자 오경보율이 아니다.
의심을 낙상으로 답해도 여기서는 확인 대상으로 세지만 3분류 정답은 아니다.

| 실제 라벨 | YOLO 원래 요청 | Cloud 확인 대상 | 둘 중 하나라도 확인 대상 |
|---|---:|---:|---:|
| 낙상 25개 | 22/25 (88%) | 25/25 (100%) | 25/25 (100%) |
| 낙상 의심 25개 | 17/25 (68%) | 25/25 (100%) | 25/25 (100%) |
| 정상 34개: 불필요한 확인 | 13/34 (38.2%) | 6/34 (17.6%) | **16/34 (47.1%)** |
| 확인 대상 영상 합계 | 52 | 56 | 66 |

둘 다 양성인 영상은 42개다. `52 + 56 - 42 = 66`이며 중복 영상은 두 번 세지 않았다.

**YOLO 낙상 22개를 검수된 성공 수로 쓰면 안 된다.** 413은 이불 위 추정 자세 때문에
대상·사건 근거가 보류되어 있다. 기존 동일 기준 검수를 재계산한 YOLO 결과는 아래와 같다.

| YOLO 대상·사건 검수 반영 | 수 |
|---|---:|
| 낙상: 대상과 사건 시점 확인 | 21/25 (84%) |
| 낙상 의심: 대상 확인 | 17/25 (68%) |
| 정상: 불필요한 요청 | 13/34 (38.2%) |

Cloud가 413을 낙상으로 판정했다고 YOLO의 보류를 해제하지 않았다.
Cloud 응답에는 대상자 ID·박스가 없으므로 Cloud/합산 결과는 장면 단위이며,
YOLO 대상자 검수와 같은 수준의 사람별 검증이 아니다. 의심의 시간 GT 누락도 그대로다.

## 2. 무엇을 보완했나

YOLO 요청이 없던 **11개**를 Cloud가 확인 대상으로 남겼다.

- 낙상 3개: **442, V002, V044**.
- 낙상 의심 8개: **207, 411, 431, 441, V010, V011, V022, V023**.

여기에 YOLO 근거가 보류된 413까지 포함하면, 검수된 YOLO 성공이 없지만 Cloud가
확인 대상으로 남긴 영상은 12개다. `요청 없음 11개 + 보류 1개`를 구분해서 기록했다.

반대로 이번 84개에서는 Cloud가 정상으로 놓친 낙상·의심이 없어서,
YOLO를 더함으로써 Cloud 단독보다 새로 구한 낙상·의심은 없었다.
이 결과는 이 데이터에서의 결과이지 두 모델이 앞으로도 놓치지 않는다는 보장이 아니다.

## 3. 어떤 부작용이 있었나

Cloud는 정상이라고 답했지만 YOLO 요청 때문에 남은 정상 영상이 **10개**다.

**55, 108, 308, 410, 425, V005, V006, V026, V029, V030**.

수면·정상 눕기·스트레칭과 425 고양이 오검출 등이 포함된다.
Cloud 단독의 정상 오탐 6개에 이 10개가 더해져 합산에서는 16개가 됐다.
반대로 YOLO가 요청하지 않은 정상 V008·V015·V016을 Cloud가 의심하여,
YOLO 단독과 비교하면 정상 확인 대상이 13개에서 16개로 늘었다.

따라서 **OR 규칙을 곧바로 보호자 알림 조건으로 쓰면 안 된다.**
이 시험은 질문·재확인이 필요한 후보를 넓게 모으는 단계까지다.
답변·새 관측을 포함한 최종 판정과 실제 알림은 평가하지 않았다.
기존 Cloud 3분류 정확도 72/84(85.7%)는 그대로이며, 합산에 임의의 3분류 정답을 부여하지 않았다.

## 4. 이번에 검증하지 않은 것

- **사람별 사건 병합:** 영상별 중복 집계일 뿐이다. 서로 다른 사람의 ID는 보존했고,
  Cloud 장면 판정을 특정 YOLO ID에 붙이거나 실제 사람 수로 해석하지 않았다.
- **확인 주기:** 영상마다 Cloud를 한 번 확인한 조건이다. 실제 60초/5분 주기라면
  그 사이 영상이 빠질 수 있으므로 이 포착률을 그대로 적용할 수 없다.
- **동시 실행·지연:** YOLO는 영상 시각, Cloud는 요청 왕복 시각이다. 서로 다른 시간을
  단순히 최솟값으로 합쳐 실제 감지 지연이라고 만들지 않았다.
- **10초 입력:** 원본은 약 5초다. 10초·12장 또는 10초·24장 시험이 아니다.
- **실물·음성·푸시:** Jetson 동시 부하, Agent 답변, 웹 푸시 수신은 포함하지 않았다.

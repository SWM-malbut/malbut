  앞서 진행한 [60초 시험](VLM_PAID_TIMEOUT60_20260926.md)은 별도 결과로 유지.

### 라벨 정답과 응답 검사 점수가 다른 이유

영상 라벨 정답은 모델이 답한 낙상 / 낙상 의심 / 정상을 정답과 비교한 수다.
라벨을 읽을 수 없거나 시간 초과가 난 요청도 분모에 남기고 정답으로 세지 않는다.

두 번째 점수는 라벨이 맞으면서 박스 좌표 등 응답 검사까지 통과한 수다.
검사 통과는 실제 사람의 손·발까지 박스를 정확히 잡았다는 뜻은 아니다.

- Gemini: 좌표 범위 오류 19건, 박스 크기 조건 오류 1건. 총 20건 중 라벨 자체는
  18건이 맞아, 라벨 점수 73개와 응답 검사 포함 점수 55개가 달라졌다.
- Gemma: 좌표 범위 오류 25건, 박스 크기 조건 오류 1건. 총 26건 중 라벨 자체는
  20건이 맞아, 72개와 52개가 달라졌다.
- 이번 응답 오류는 JSON 바깥의 코드 블록 때문이 아니라 박스 값 문제였다.
  좌표를 임의로 나누거나 고쳐서 통과시키지 않았다.
- 나머지 완료 모델에서는 응답 검사 오류가 없었다. 명시적인 답변 거부·안전 차단은
  이번 478건에서 기록되지 않았다. 다른 데이터에서도 없다는 보장은 아니다.

  Gemma와 라벨 정답 수가 같고, 낙상·의심을 정상으로 답한 경우는 5건이었다.
- **Gemini는 73개로 한 개 더 맞혔지만 좌표 오류 20건이 있다.** 한 번의 84개 시험에서

- **GLM은 저렴하지만 현재 20초 기준에서 시간 초과 10건과 정답 감소가 컸다.**
  9개 시험의 짧은 응답 시간이 이번 전체 평가에서도 유지되지는 않았다.

따라서 운영 모델을 바로 바꾸지 않는다. 전체 비교를 마친 뒤 좌표 출력 문제를 별도

SWM25-186 / 2026-09-26

이전 요청이 정확히 언제 끝났는지는 당시 20초에 연결을 끊었으므로 여전히 알 수 없다.
위 시간은 이번에 새로 보낸 요청의 측정값이다. 원인을 특정하려면 반복 측정이 필요하다.

## 구현과 검증

- 기본 20초와 별도 60초 시험을 실행 계획·결과에서 구분.

- `usable_reply_within_20s`: 20초 안에 영상 판정을 읽을 수 있는 응답을 받았는지.
  정답 여부나 실제 사람 박스가 정확한지까지 뜻하지 않는다.

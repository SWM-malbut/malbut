# Cloud 출력 형식 진단 — 원래 채점과 별도

Gemma Cloud 초기 응답에서 Markdown 코드 블록으로 감싼 JSON이 관측되어 추가한
**사후 보조 분석**이다. 원래 실험의 프롬프트/응답/결과/엄격한 채점은 변경하지 않는다.

- 전체 응답을 감싼 단 하나의 ` ```json ` 또는 언어 없는 코드 블록만 벗겨서 재검증한다.
- 추가 설명에서 JSON을 찾아내거나, 키/라벨/내용을 수정하지 않는다.
- 원래 JSON 스키마와 완료 상태 검증을 동일하게 적용한다. 정답 라벨은 파싱에 사용하지 않는다.
- 비교하는 모든 모델에 같은 처리를 적용한다. 실패 영상도 원래 분모에 남는다.
- 이를 **형식만 정리한 판단 정확도**로 따로 표기한다. 원래 연동 성공률/엄격 정확도를
  대신하거나 Cloud가 구조화 출력을 지원한다는 근거로 쓰지 않는다.
- 추가 모델 호출, 반복 추론, 모델별 프롬프트 수정은 하지 않는다.

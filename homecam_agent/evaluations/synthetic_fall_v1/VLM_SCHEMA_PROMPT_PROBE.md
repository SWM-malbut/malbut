# Ollama 출력 명세 전달 확인

41개 기본 비교 실행과는 **별도 실험**이다. 기본 비교에서는 JSON Schema를 Ollama의
`format` 옵션으로만 넘겼다. `--schema-in-prompt`는 같은 스키마를 사용자 프롬프트
본문에도 덧붙인다. 이미지, 추출 시각, 모델, 생성 옵션, 정답과 검증 기준은 그대로다.

[Ollama 공식 가이드](https://docs.ollama.com/capabilities/structured-outputs)는 `format`과
함께 프롬프트에도 스키마를 전달할 것을 권장한다. 이 권고가 이번 모순의 원인을
확정하는 것은 아니다. 첫 순번 영상 한 개로 전달 방식의 영향을 우선 확인한 뒤,
같은 설정으로 나머지 40개도 실행한다. 첫 영상을 중복 실행하거나 합산하지 않는다.

- 기본 비교: `vlm-qwen25vl7b-20260910-frames-v2`.
- 별도 확인: `vlm-qwen25vl7b-20260910-schema-probe-v1`.
- 첫 입출력 확인만 한 `frames-v1`은 기본 비교 결과에 합치지 않는다.
- 스키마 본문 포함 여부, 실제 사용자 프롬프트, 요청/응답 해시를 별도로 보관한다.
- 한 영상의 개선으로 41개 성능이나 다른 모델 대비 우위를 주장하지 않는다.
- 기본 비교 때 실행한 원본 코드는 결과 디렉터리의 `runner_source.py`에 보관한다.
  해당 소스의 SHA256은 `run.json`에 기록된 값과 일치한다.

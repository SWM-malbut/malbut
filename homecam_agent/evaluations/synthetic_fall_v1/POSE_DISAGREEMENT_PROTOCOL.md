# 누운 자세 관측 후 기하 불일치 지속 시 확인 요청 — 별도 실험

2026-09-17, 한 프레임 흔들림 후 복귀를 기다리는 첫 실험은 추가 후보 0건이었다.
V034의 실제 출력을 확인하니 넓은 박스·관절 배치는 유지되지만 몸통 각도가
여러 프레임 연속 달라졌다. 첫 실험의 결과와 코드는 그대로 보존한다.
첫 실험의 수치를 바꾸지 않고, 아래의 다른 요청 조건을 별도로 비교한다.

- 같은 84개, 같은 2,224개 Pose와 기존 pose-loss + 중복 억제를 사용한다.
- 같은 사람의 실제 낮은 자세가 연속 3표본 이상, 0.4초 이상 관측되어 있어야 한다.
- 이어지는 **실제 관측** 2표본이 몸통 각도 등에서는 낮은 자세 조건을 충족하지 못하되
  박스 가로세로비 ≥ 1.1, 관절 가로세로비 ≥ 2.0, 관절 세로 범위 비율 ≤ 0.7이어야 한다.
- 마지막 낮은 자세 관측 후 0.5초 이내에만 요청 가능하다. 3개/0.4초/2개/0.5초는
  기존 pose-loss 확인 요청에서 사용한 보수적 약한 증거 구성을 그대로 가져왔다.
- 불일치 시간을 누운 시간에 더하지 않는다. 앞서 본 낮은 자세와 현재 불일치를
  서로 다른 증거로 기록하고, '현재도 누웠다/넘어졌다'고 확정하지 않는다.
- 현재 자세가 관측되므로 missing이라고 기록하지 않는다. 현재 Pose·현재 관측 ID와
  이전 낮은 자세의 실제 프레임·관측 ID를 모두 남긴다.
- 정지 여부는 전제 조건이 아니다. 다른 ID·미검출·불충분한 관절·미할당·모호한 연결·
  anchor 변경·시각/해상도 변경·명확한 다른 자세·유효 depth의 반증은 이어 붙이지 않는다.
- 낮은 자세로 돌아오면 이전 불일치를 붙여 발화하지 않고 이 분기의 관측을 새로 시작한다.
- 출력은 found_down 유형의 확인 요청이다. 낙상 확정이나 보호자 알림을 직접 만들지 않는다.
- 기존 후보·증거는 보존한다. 첫 실험과 결합하지 않는다. 프롬프트·VLM 호출도 바꾸지 않는다.
- 결과 확인 후 임계값 추가 조정 없음. 전체 데이터에서 정상 추가 요청과 첫 요청 시각도
  비교한다. 새 출력은 RGB와 기존 박스를 별도로 대조한다.

이는 같은 개발 데이터에서 원인 분석 후 만든 가설이다. 독립 검증 결과로 발표하지 않는다.
첫 후보가 늘어도 VLM 이후 정확도가 늘었다고 간주하지 않는다.

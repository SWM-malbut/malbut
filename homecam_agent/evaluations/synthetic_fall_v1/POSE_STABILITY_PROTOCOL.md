# 관측된 자세의 일시적 흔들림 비교 — 2026-09-17

운영 기본값·모델·라벨·박스는 바꾸지 않는다. 이미 본 합성 개발 영상 84개와
기존 2,224개 실제 Pose 출력을 사용한다. 새 모델·VLM·클라우드 호출은 없다.
이번 범위는 **검출된 관절의 일시적 기하 변화**이며, 미검출 보간이 아니다.

## 결과 확인 전에 고정한 조건

- 기준은 기존 pose-loss + 요청 중복 억제(39개 요청)다.
- 동일한 pose-loss 입력에 기존 중복 억제만 적용한 대조군이 같은 결과인지 먼저 확인한다.
- 기존의 낮은 자세 정의, 관절 신뢰도·개수·샘플링·추적 결과는 그대로 사용한다.
- 같은 트랙에서 usable인 자세가 연속 관측될 때만 최근 2초를 살핀다.
- 낮은 자세 조건을 벗어난 프레임 중, 박스 가로세로비 ≥ 1.1,
  관절 가로세로비 ≥ 2.0, 관절 세로 범위/박스 높이 ≤ 0.7인 경우만
  '몸 전체 배치는 넓지만 일부 기하가 불일치한 관측'으로 구분한다.
  이 수치는 기존 낮은 자세·compact body 조건에서 가져왔으며 낙상 확정 기준이 아니다.
- 이 불일치 관측은 창 안에서 최대 1개만 보존한다. 낮은 자세로 세지 않는다.
  불일치 전후 간격도 낮은 자세 관측 시간에 더하지 않는다.
- 어깨·골반 구성(anchor names)이 바뀌면 초기화한다.
- missing, 불충분한 관절, 모호한 연결, 미할당 Pose, 0.5초 초과 표본 간격,
  해상도 변경, 시각 역행, 명확히 다른 자세, 유효 depth가 바닥 위를 가리키면 초기화한다.
- 최신 프레임이 실제 낮은 자세여야 한다. 최소 3개 낮은 자세 표본,
  창 안 표본 중 낮은 자세 비율 ≥ 0.75, 실제 인접한 낮은 자세 표본 간격 합 ≥ 0.6초가 필요하다.
- 창 안에 불일치 관측이 있을 때만 추가 후보를 만든다. 누운 상태의 관측이지
  쓰러지는 과정의 증거는 아니므로 found_down/확인 요청으로만 출력한다.
- 다른 ID의 기록은 합치지 않는다. 정지한 사람을 제거하지 않는다.
- 기존 후보와 추가 후보를 같은 요청 중복 억제로 처리한다. 모든 원본 후보는
  요청 또는 원문 증거 업데이트로 보존한다. 먼저 나온 추가 요청으로 기존 요청의
  시각이 앞당겨질 수 있으므로, 발생 전 요청인지도 확인한다.
- --control은 새 후보를 만들지 않는다. 기본값은 실험 실행이며 배포 설정과 무관하다.

## 비교와 채택

전체 84개를 실행한 뒤 라벨과 결합한다. 새로 출력된 영상뿐 아니라 정상의 추가 호출,
없어진 요청·증거, 첫 요청 시각, 사건 시작 구간 대비 지연을 함께 기록한다.
GT 박스는 추론에 사용하지 않으며 출력 연결의 검토에만 사용한다.
시각·대상 연결이 확인되지 않은 후보를 재현율 개선으로 확정하지 않는다.
동일 84개에서 결과를 본 뒤 수치를 바꿔 재실행하지 않는다. 추가 조정은 별도 실험으로 남긴다.
후보 지연은 영상 시각 기준이며 VLM 응답·실물 종단 간 지연이 아니다.

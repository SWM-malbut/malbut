# 같은 기준으로 다시 검토한 YOLO-Pose 비교

## 결론

기존 표의 5단계 모두 실제 요청 대상자와 사건 시점을 같은 기준으로 대조했다.
단순 요청 발생률과 일부 단계만 검토한 수치를 섞지 않는다.

| 단계 | 낙상: 대상·사건 시점 확인 / 25 | 의심: 대상 확인 / 25 | 정상: 불필요 요청 영상 / 34 |
| --- | --- | --- | --- |
| 최초 기준 | 15 (60%) | 15 (60%) | 10 (29.4%) |
| 판단 조건 개선, n + 기존 비율 변형 | 17 (68%) | 15 (60%) | 10 (29.4%) |
| n + 원본 비율 유지 | 18 (72%) | 18 (72%) | 11 (32.4%) |
| s + 원본 비율 유지 | 20 (80%) | 16 (64%) | 13 (38.2%) |
| s + 추가 판단 조건 | 21 (84%) | 17 (68%) | 13 (38.2%) |

**낙상은 최초 15→최종 21개, 60→84% (+24%p)**다. 이전에 요청 발생 기준으로
쓴 60→88%를 실제 사건 감지 성과로 사용하지 않는다. 정상 영상의 불필요 요청은
10→13개로 늘었다. 이 수치는 보호자 알림 정확도나 VLM 정확도가 아니다.

의심 영상은 25개 중 18개에 시간 라벨이 없다. 따라서 의심 열은 모든 단계에서
대상자 확인율이며, 시간까지 검증된 재현율로 부르지 않는다. 시간 GT가 있는 같은
7개만 따로 보면 대상·시점 확인은 순서대로 **3/7, 3/7, 2/7, 3/7, 3/7**이다.
나머지 영상의 시작 시각을 새로 추정하거나 GT에 추가하지 않았다.

## 모든 단계에 적용한 기준

1. 사용자가 확정한 동일한 84개 영상, 25/25/34 라벨, 보이는 영역 박스 533개를 고정한다.
2. 요청의 실제 근거 프레임에서 해당 대상자를 확인한다. 다른 사람·가구·반려동물은
   양성 성공으로 세지 않는다. 사람이 일부만 보여도 누구인지 확인할 수 있으면 대상
   대응은 인정한다. 이 기준은 박스 IoU나 관절 위치 정확도를 보장하지 않는다.
3. 낙상은 넘어지는 중 또는 이후 자세라는 근거도 확인한다. 실제 근거 시각과 요청
   시각이 모두 승인된 시작 범위보다 이르지 않아야 한다. 시작 범위 안의 요청은
   경계 불확실로 따로 표시한다. 이번 성공 낙상 요청은 모두 시작 범위 뒤다.
4. 관련 근거를 확인하지 못하면 보류한다. **보류를 성공에 넣거나 분모에서 빼지 않는다.**
5. 한 영상의 중복 요청은 성공 1개로만 센다. 실제 요청 건수는 비용 지표로 별도 보존한다.
6. 정상 영상에서는 사람을 잡았든 고양이를 잡았든 발생한 요청을 불필요한 요청으로 센다.
   425의 고양이 오검출을 빼서 정상 요청 비율을 좋게 만들지 않는다.
7. 시간 라벨이 없으면 대상자 검토만 기록한다. 시간 GT 유무가 다른 영상을 섞어 감지
   지연을 계산하지 않으며, 영상 시각 차이를 실물 처리 지연으로 부르지 않는다.

## 실제 검토 범위

- 단계별 요청은 40 / 42 / 50 / 51 / 53건, 합계 **236건**이다.
- 동일 영상·근거 프레임·예측 박스/관절·요청 시각·후보 유형이 모두 같은 경우에만
  화면을 공유했다. 원래 단계별 요청은 각각 보존했다.
- 총 **154개 서로 다른 근거 묶음, JPG 31장**을 직접 확인했다. 각 묶음에는 근거 시작,
  실제 요청 근거, 가장 가까운 최종 검수 프레임이 있다. 미검수 박스 보간은 하지 않았다.
- 바닥 대상자와 옆 사람이 겹친 414·V004·V023·V027 등도 요청한 ID의 실제 위치를 대조했다.
- 원래 없던 후보를 만들거나 누락한 요청을 추정하지 않았다. 후보 없는 영상도 분모에 남는다.
- 검토 결과는 비블라인드 assistant 출력 검토다. 사용자 라벨 확정이나 독립 평가자의
  블라인드 검수, 모든 영상 전체 재생 검토를 대신하지 않는다.

이불·침대 영역의 추정 관절이라 사건 관련 자세를 확정하지 못한다. **오검출 확정이 아니라
근거 확인 불가로 보류**한다. 이 영상의 낙상 정답 자체를 바꾼 것이 아니다.

복사하고 최신 결과에서만 1개 뺀 계산이 아니다.

## 남는 해석

- 최신 s 조건에서 확인된 낙상 21개, 요청 없는 3개(442·V002·V044), 보류 1개(413)다.
- n + 비율 유지보다 최신 s는 낙상 3개 많지만 의심 1개 적고 정상 요청 2개 많다.
  전체 항목에서 s가 우위라는 결론은 아니다.
- 마지막 추가 조건이 구제한 V027·V048은 1280×720 영상이다. 실제 카메라와 같은
  640×400 영상에서 마지막 규칙의 추가 성과는 없다.
- 검출기나 판단 조건을 이번 보정 중 변경하지 않았다. 기존 출력의 검토·채점만 했다.
- 개선 후 VLM 정확도, Jetson 성능, 미사용 영상에서의 일반화는 이 결과에 포함되지 않는다.

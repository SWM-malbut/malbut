# s 모델 후속 개선 결과

> 후속 대조: 기존부터 최신까지 동일한 대상·시점 검토를 완료했다.
> 성능 비교에는 [같은 기준으로 보정한 표](UNIFORM_POSE_COMPARISON_20260918.md)를 사용한다.
> 아래 22/25는 원래 요청 발생 수이며, 보정된 최신 낙상 결과는 21/25다.

## 현재 결론

`YOLO26s-Pose + 비율 유지`의 기존 출력에 두 확인 조건을 추가했다.
골반이 안 보여도 머리·팔이 반복 관측되면 확인을 요청하고,
최종 누운 각도가 흔들려도 실제 몸의 하강이 반복 관측되면 확인을 요청한다.
**V027·V048을 추가로 요청했고, 정상 영상 요청 수는 늘지 않았다.**

개발용 실험 코드와 재평가만 완료했다. 운영 감지기·로봇·웹 배포는 변경하지 않았다.
V023 미탐, 425 고양이 오검출, 108 중복 요청은 남아 있다. VLM은 아직 호출하지 않았다.

## 비교

사용자가 확정한 합성 영상 84개와 보이는 영역 박스 533개를 그대로 사용했다.
이전에 실제 추론한 동일한 2,224프레임의 s 출력·ID를 재생했다. 모델을 새로 학습하거나
다시 추론한 결과가 아니다. 이번에는 판단 조건만 바꿨다.

| 조건 | 낙상 영상 요청 / 25 | 의심 영상 요청 / 25 | 정상 영상 요청 / 34 | 총 요청 건수 |
| --- | --- | --- | --- | --- |
| n + 기존 비율 변형 (보존한 비교군) | 17 | 15 | 10 | 42 |

요청 영상 수와 요청 건수는 다르다. 마지막 조건은 52개 영상에서 53건을 요청했다.
108에서 2건이 발생한다. 정상 요청은 불필요한 VLM 확인 요청이며 보호자 오경보 수는 아니다.
기존 n보다 정상 요청이 3개 많다는 비용도 그대로 남는다.

위 값은 영상 내 요청 발생 수이지 **낙상 확정 정확도 또는 VLM 정확도**가 아니다.
최초 s 요청 51건을 RGB와 대조한 결과, 낙상 요청 21개 중 413은 침대 위 이불 영역을
잡은 이른 요청이라 성공으로 보류했다. 개선 후에도 같다.
실제 확인 대상자에 붙은 낙상 요청은 **20→21개**, 의심 요청은 **16→17개**다.
이는 비블라인드 assistant 출력 검토이며 사용자 정답 라벨을 바꾼 것이 아니다.

두 새 사례 V027·V048은 모두 **1280×720 원본**이다. 실제 카메라와 같은 640×400
기존 41개만 보면 요청 수는 여전히 낙상 13/14, 의심 3/7, 정상 5/20이다.
이번 증가만으로 실물 저해상도 카메라 성능이 향상됐다고 말할 수 없다.

## 무엇을 바꿨나

1. **상체 부분 관측:** 골반이 없다는 이유로 무조건 끝내지 않는다. 감지 점수,
   머리·어깨·팔 관절의 신뢰도와 배치, 실제 관측 4개·0.6초를 함께 확인한다.
   가려진 골반을 만들어 내거나 자세 계산 성공으로 바꾸지 않는다.
2. **짧은 하강 관측:** 이전 자세와 비교해 박스 높이, 비율, 같은 이름의 관절 하강량과
   속도를 확인한다. 후속 관측 3개 조건은 V048에서 두 개만 모으고 끝났다.
   기존 실험을 보존한 뒤 후속 관측 2개·0.15초 조건을 별도 비교했다.
   이전 기준 관측도 필요하므로 전체 판단은 단일 프레임에 의존하지 않는다.
3. **안전 처리:** 시간·해상도·영상 변경, 대상 ID의 모호함, 겹친 미할당 관측,
   측정된 바닥 거리와의 모순은 근거를 이어 붙이지 않는다. 다른 위치의 미할당 검출 때문에
   정상적으로 이어지는 모든 사람의 근거를 지우지는 않는다.
4. **같은 추적의 기존 요청:** 추가 근거는 업데이트로 보존하고 요청을 중복 생성하지 않는다.
   서로 다른 ID를 사람 하나라고 새로 합치는 규칙은 넣지 않았다.

새 조건도 낙상 확정이나 자동 알림이 아니라 **VLM으로 확인할 후보**다.
카메라 이동 보정이 없고, 앉기·눕기가 조건을 만족할 수 있다는 한계를 요청에 남긴다.
이미 살펴본 개발 데이터를 참고한 개선이다. 별도 검증 세트 성능으로 해석하지 않는다.

## 미해결 사항

- **V023:** 누운 사람의 별도 출력이 f000·106·115·120에만 있다. 중간에는 옆 사람의
  출력만 유지된다. 추적 ID를 길게 붙여도 누락된 대상 관측은 생기지 않는다.
- **425:** 고양이에 높은 관절 점수를 출력한다. 관절 점수만으로 사람이 맞는지 보장할 수 없다.
  감지 점수 0.45 미만을 전부 제거하면 실제 낙상 107의 요청 근거(약 0.252)도 제거된다.
  이것은 첫 요청 근거의 대조이며 임계값 변경 후 재현율 실험은 아니다.
- **108:** 전신 관측 f026→043 사이 공백이 약 1.42초다. 전신 ID1은 끝나고 ID3이 생긴다.
  그 사이 얼굴 위주의 ID2가 있지만, 현재 직접 대응 기반 규칙으로 세 ID를 같은 사람이라고
  이어 붙일 충분한 근거가 없다. 위치만으로 합치지 않아 중복 2건이 남았다.
- **413:** 최초 요청은 아직 바닥에 떨어진 뒤의 확인이 아니다. 정답 처리하지 않는다.
- 최종 요청 없는 낙상: 442·V002·V044. 의심: 207·411·431·441·V010·V011·V022·V023.

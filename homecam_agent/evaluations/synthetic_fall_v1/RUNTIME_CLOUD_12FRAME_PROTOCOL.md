## 고정 조건

- 모델: 기존에 평가한 Gemma4 31B Cloud. Mac Ollama의 인증을 SSH 터널로 이용한다.
  Mac에서 모델을 추론하는 것이 아니다. 직접 Cloud API 인증 경로는 별도 검증 대상이다.
- 데이터: 최종 검토한 합성 영상 84개, 낙상 25 / 낙상 의심 25 / 정상 34.
  `fall84-v2-r1-20260917`의 영상·라벨 해시를 검사한다. 수정하거나 일부를 제외하지 않는다.
- 방식: YOLO를 거치지 않고 전부 호출한다. 박스·정답·판단 이유·영상 ID·센서·음성·Agent 답변은
  모델에 보내지 않는다. 전체 장면을 보는 `crosscheck` 요청이다.
- 입력: 마지막 최대 10초의 실제 프레임을 시간순으로 12장 추출한다.
  원본 비율을 유지해 640×400에 넣고 빈 공간은 검정색으로 채운다. 자르거나 늘려 왜곡하지 않는다.
  JPEG 품질 90, 실행 어댑터의 메타데이터 제거를 거친다.
- 기존 영상은 약 5.1초다. 부족한 앞부분을 복제하지 않고 `history_incomplete=true`로 보낸다.
  따라서 약 0.47초 간격인 이번 결과는 **10초 전체에서 12장을 고른 결과가 아니다.**
- 프롬프트·출력 검증: `ollama_cloud_fall.py`의 실행 코드 그대로 사용한다.
  `assessment/explanation`을 기존 3분류 채점 형식으로 변환하되 판정은 바꾸지 않는다.
  바깥 JSON 코드 블록 하나는 허용하며, 잘못된 JSON 내용은 복구하지 않는다.
- 요청당 20초, 순차 호출, 자동 재시도 없음. temperature=0, num_predict=512, thinking=false.
- 호출 전마다 Free 계정을 확인하고, 인증·결제·한도 오류에서 중단한다.
  무료 크레딧 외 결제/충전 설정은 바꾸지 않는다. 원격 무료 한도는 공급자가 관리한다.

## 채점과 기록

- 3분류 정확도: 낙상·낙상 의심·정상 각각 정답과 정확히 일치한 수 / 84.
- 확인 대상 포착률: 낙상 또는 의심 50개 중 모델이 낙상 또는 의심으로 남긴 수 / 50.
- 정상으로 놓침: 같은 50개 중 정상이라고 답한 수 / 50.
- 정상 오탐: 정상 34개 중 낙상 또는 의심으로 답한 수 / 34.
- 시간 초과·응답 오류·판단 불가는 따로 기록하며 정상으로 바꾸거나 분모에서 빼지 않는다.
- Cloud 요청 시간의 중앙값·p95를 기록한다. SSH 왕복을 포함한다.
  영상 전체를 본 오프라인 분류이므로 **낙상 발생부터 감지까지의 지연이 아니다.**
- 요청 해시·추출 시각·입력 JPEG 해시·원응답·결과를 요청마다 저장한다.
  실행 중 끊긴 요청을 몰래 재호출하지 않는다. 코드와 자료 해시를 실행 전후 확인한다.

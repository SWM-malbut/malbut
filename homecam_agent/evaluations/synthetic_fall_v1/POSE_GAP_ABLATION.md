# 추가 비교: 재등장 기록 이어 쓰기와 관측 누락 요청 분리

2026-09-10. 최초 실험 결과를 본 뒤 추가한 원인 분리 비교다.
사전 계획된 독립 검증이나 새 데이터 성능으로 해석하지 않는다.

최초 `pose-gap`에서 107의 마지막 관측 기반 확인 요청 외에, 재등장한 낮은 자세를
이어 쓸 때 정상 영상 55에서도 새 요청이 나왔다. 정상 영상 108에서는 다른 트랙에
추가 요청이 나왔으며, 410은 기존보다 먼저 요청했다.

새 `pose-loss` 실행은 **재등장하면 이전 낮은 자세 기록을 끊고**,
‘낮은 자세를 실제로 3회/0.4초 이상 본 뒤 2회 누락되면 확인 요청’만 남긴다.
모델·추적·기하·임계값·원본 라벨은 그대로다.

기존 방식, 최초 두 조건을 함께 켠 방식, 이번 누락 요청만 켠 방식의 결과를
모두 보존한다. 55를 통과하도록 숫자를 바꾸지 않는다.
이 추가 비교로 더 나은 결과가 나와도 별도 영상·실물 검증 전 제품 기본값으로 넣지 않는다.

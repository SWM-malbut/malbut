# Cloud RGB 12장 ↔ 6장 비교

2026-09-19. 직전 12장 평가와 같은 영상에서 장수만 줄인다.

- 대조군: `fall84-runtime12-cloud-20260919`의 완료된 84회 호출 결과. 재호출하지 않는다.
- 비교군: 같은 84개에 6장으로 새로 84회 호출한다. 기존 결과를 덮어쓰지 않는다.
- 고정: Gemma4 31B Cloud, 실행 프롬프트, 640×400 비율 유지·여백 처리, JPEG 품질,
  temperature=0, num_predict=512, thinking=false, 20초 제한, 순차 요청·재시도 없음.
- 장면 전체를 보는 VLM 단독 평가이며 YOLO·정답·박스·센서·음성·Agent 답변은 보내지 않는다.
- 실제 길이 약 5.1초인 원본 전체에서 균등 추출한다. 양 끝 프레임은 유지한다.
  6장은 12장에서 단순 홀수/짝수만 골라내지 않고 같은 균등 추출식으로 다시 고른다.
  따라서 장수와 그에 따른 중간 추출 시각·영상만 달라진다.
- 요청의 최대 시간 창 10초 및 앞부분 누락 표시는 기존과 동일하게 유지한다.
  실제 없는 5초를 생성하거나 반복하지 않는다. 정확히 5초로 잘라 영상 범위를 바꾸지도 않는다.
- 시작 전에 대조군 자료·코드 스냅샷·원응답을 검사하고 84개 기존 요청을 재구성해 해시를 확인한다.
  코드·모델 메타데이터·라벨·조건이 장수 외에 달라졌으면 호출하지 않는다.
- Free 계정을 호출마다 확인하며 유료 설정을 변경하지 않는다. 인증·결제·한도 오류에서 중단한다.
- 채점: 84개 전체 3분류 정확도, 라벨별 정답, 낙상·의심을 정상으로 놓침, 정상 오탐,
  미판정·시간 초과·형식 오류, 응답 시간 중앙값·p95. 실패도 분모에서 빼지 않는다.
- 이번 결과는 **약 5초의 6장 입력**이다. 약 1초 간격을 시험할 수 있지만
  전후 상황을 더 포함하는 10초·12장과 동일한 성능이라고 주장하지 않는다.
- 한 번씩 호출하는 비교다. 서비스 부하·모델 비결정성이 있을 수 있으며 통계적 우열을 확정하지 않는다.
  소요 시간은 오프라인 요청 시간이지 실제 낙상 발생부터의 감지 지연이 아니다.

기존 설정은 [12장 평가 조건](RUNTIME_CLOUD_12FRAME_PROTOCOL.md)을 따른다.
운영용 예시 설정의 `max_images=12`는 변경하지 않는다.

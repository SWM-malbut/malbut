# Gemma 관찰·추측 분리 실험 (2026-09-17)

## 목적과 범위

V034 등에서 넘어지는 과정 미관측·움직임 부족을 휴식의 근거로 해석하는 오류를 확인했다.
출력을 관찰/알 수 없는 내용/판정으로 나누면 도움이 되는지 비교한다. 이전 추가 문구 B는
미탐이 늘어 채택하지 않았으며 이번 실험의 대조군으로 사용하지 않는다.
이미 확인하고 개선에 사용한 합성 개발 데이터다. 독립 평가나 실물 안전 성능이 아니다.

## 실행 전 고정

- 입력·라벨: frozen 84개 (낙상 25 / 의심 25 / 정상 34), 사용자 라벨/박스 수정 없음.
- 모델: 기존 로컬 Gemma4:12b, 동일 digest / Ollama / 옵션 / 12장 JPEG90 / 해상도.
- gated: 기존 A 39건 + V034 f077의 실제 A 1건, 같은 후보 40건, 나머지 44건 미호출.
- full: 기존 A의 전체 영상 84건과 정확히 같은 RGB 및 샘플링 시점.
- 총 124회, gated 후 full. 시간 초과 300초, 재시도 없음, 병렬 추론 없음.
- 변경: system의 출력 지시, JSON 스키마 및 user의 스키마 안내 부분만 변경.
  RGB 이미지·시간·user 본문·모델 옵션은 원본 요청을 재구성해 해시 검증한다.
- 출력: observations(visible_facts_ko / unknowns_ko), assessment(기존 3개 필드).
  observations는 모델의 서술이지 검증된 사실이 아니다. 코드가 참이라고 간주하지 않는다.
- 원래 판정 기준은 유지한다. 특정 장면·GT·이유·YOLO·depth·음성은 보내지 않는다.
- 코드가 모델 판정을 재분류하지 않는다. 전체 응답 검증 후 assessment를 그대로 채점한다.
  관찰 필드가 잘못되면 전체 응답을 invalid로 남긴다. 실패·미호출도 기존 규칙대로 남긴다.
- Ollama 전송 스키마의 문자열 길이 제약은 생략하고 로컬 검증에 적용한다.
  의미상 전체 스키마는 프롬프트에 포함한다. 이전 maxLength 문법 컴파일 문제를 피한다.

## 판정과 중단

주요 지표는 낙상·의심 50개 중 확인 대상으로 남긴 수, 정상 34개의 불필요한 확인,
기존 대비 새로운 정상 오판, 3분류 정확도, 응답 유효성, 요청 지연이다.
gated 정확도 분모는 호출된 40건이며 full 분모는 84건이다. 미호출을 정상으로 바꾸지 않는다.
지연은 Mac/SSH 요청 지연이며 실제 사건 발생부터 로봇의 조치까지 지연이 아니다.
출력이 길어져 지연이 달라질 수 있으므로 순수한 프롬프트 문구만의 효과로 해석하지 않는다.

문법/권한/모델 오류(HTTP 400/401/403/404)는 중단하며 증거를 보존한다. 일반 호출 실패는
실패 결과로 저장하고 나머지를 진행한다. 중단 후 자동 재시도/덮어쓰기하지 않는다.
실행 중 문구·임계값 수정 금지. 운영 기본값 변경·배포·질문·알림 연결 없음.
완료 후 의심 개선과 정상 오탐·낙상 회귀를 함께 보고 채택 여부를 판단한다.

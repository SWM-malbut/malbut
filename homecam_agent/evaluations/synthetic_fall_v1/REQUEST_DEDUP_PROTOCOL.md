## 합칠 수 있는 경우

여기서 합치는 것은 확인 요청이며, 사람 ID나 Pose 자체가 아니다.
새 요청을 없애 버리는 대신 기존 요청의 추가 근거로 보관한다.

1. 작은 박스 면적이 큰 박스의 50% 이하이고, 작은 박스의 90% 이상이 큰 박스 안에 있다.
2. 같은 이름의 코·양쪽 눈이 모두 관측되고 위치가 가깝다.
   관절 신뢰도는 0.65 이상, 거리 한도는 작은 박스 대각선의 8%다.
3. 적어도 한쪽의 어깨·팔꿈치·손목 세 관절도 각각 같은 위치를 가리킨다.
   신뢰도는 0.65 이상, 거리 한도는 작은 박스 대각선의 10%다.
4. 이 관계가 실제 동시 관측 3회 이상, 0.3초 이상 이어져야 한다.
   인접 관측 간격은 최대 0.3초다. 양쪽 관측이 있는데 조건이 깨지면 즉시 취소한다.
5. 다른 후보까지 같은 관계로 연결되면 모호하므로 합치지 않는다.
   A-B, B-C를 이유로 A-C까지 연결하지 않는다.
6. 이미 요청이 있는 트랙과 직접 대응하고, 기존 요청 후 2초 이내인
   `found_down` 요청끼리만 합친다. 새로운 `fall_suspected`는 별도 요청을 유지한다.
7. 잠깐 누락된 후보는 마지막 실제 관측 후 0.5초까지만 허용한다.
   그 마지막 관측이 위 동시 관측 근거와 같아야 한다. 과거 박스를 현재로 옮기지 않는다.
   만료/모호한 연결/미할당 관측/시간·해상도 변화는 합치기 근거를 끊는다.

가만히 있다는 이유로 제외하지 않는다. 가구 여부나 정상 행동 여부를 판단하지 않는다.
3D 같은 사람 확인도 아니다. 포개져 보이는 두 사람이나 잘못 예측된 같은 관절 때문에
오합병할 위험은 남는다. 근거가 부족하면 중복을 남기더라도 별도 요청한다.
임시 관계를 영구 ID 별칭으로 저장하지 않는다. 합쳐 둔 트랙에 새 근거가 오고
관계가 더는 유효하지 않으면 독립 요청으로 되돌린다.

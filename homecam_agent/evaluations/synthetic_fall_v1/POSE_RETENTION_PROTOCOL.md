# 짧은 관측 끊김 보완 실험 — 2026-09-17

최종 수동 검수 박스를 고정하고, 이미 실행한 84개 영상의 YOLO26n-Pose 출력을 재사용한다.
검출기·박스·관절·기본 판단 조건·기존 보조 규칙은 바꾸지 않는다. 추가 규칙은 오프라인 평가에만 사용하며, 로봇·알림 경로에는 연결하지 않는다.

## 비교할 네 가지

1. control: 기존 최종 출력 그대로. 재생 시 기존 요청·근거·연결 결과와 일치해야 한다.
2. reobserved_low: 실제 낮은 자세가 잠깐의 누락을 사이에 두고 다시 관측됐을 때 확인 요청.
3. transition_followup: 기존 규칙의 급격한 변화가 한 번 잡힌 뒤, 실제 후속 자세로 재확인할 때 요청.
4. combined: 2와 3을 함께 실행. 각 효과는 별도 결과와 함께 제시한다.

이 설정은 결과를 보기 전에 고정하는 개발 실험값이다. 영상 ID·라벨·정답 박스로 분기하지 않는다. 같은 84개를 이미 살펴보고 개선 중이므로 미사용 테스트셋 성능으로 주장하지 않는다.

## 낮은 자세 재관측

- 기존 조건을 통과한 낮은 자세만 센다. 적어도 3개의 실제 관측이 필요하다.
- 첫 관측부터 마지막 관측까지의 시간 범위는 최소 0.6초, 전체 보관 범위는 2초.
- 직전 실제 관측으로부터 0.65초 이내의 명시적 `missing`만 보관한다. 새로운 영상 샘플 자체가 0.5초 넘게 끊기면 초기화한다.
- 적어도 한 번의 실제 `missing` 샘플 뒤에 다시 낮은 자세가 관측되어야 한다. 누락 중에는 요청하지 않는다.
- 다른 자세가 실제 관측되거나 관절 품질이 부족하면 낮은 자세 누적을 초기화한다.
- 누락을 사이에 둔 관측 간격은 지속 시간에 더하지 않는다. `evidenceWindowSpanSec`(첫·마지막 관측 간 시간 범위)와 `observedAdjacentSpanSec`(누락 없이 이어진 관측 간격 합계)를 구분한다.
- 요청은 `found_down` 확인 후보이며 실제로 계속 누워 있었다거나 낙상 과정을 목격했다고 단정하지 않는다.

## 급격한 변화 뒤 재확인

- 기본 판단의 `transitionSamples >= 1`과 사용 가능한 실제 낮은 자세가 함께 나온 프레임을 출발점으로 삼는다. 기존 급격한 변화 조건 자체를 완화하지 않는다.
- 그 뒤 0.65초 안에 실제 후속 관측 2개, 후속 관측 사이 최소 0.15초가 필요하다.
- 후속 관측은 동일한 어깨·골반 관절 구성을 유지하고, 몸 관절 6개 이상, 몸통 기울기 35° 이상, 박스 가로/세로 1.1 이상, 관절 분포 가로/세로 1.1 이상이어야 한다.
- 박스 높이가 출발점의 1.1배를 넘으면 지지하지 않는다. 화면의 아래 방향 이동만으로 판단하지 않는다.
- 이 조건은 낮은 자세 판정을 새로 만드는 것이 아니다. 현재 낮은 자세 판정이 불확실해도, 앞선 변화와 후속 관측을 VLM에서 확인하도록 요청한다.
- 요청은 `fall_suspected`, `requiresVerification=true`. 낙상 확정·자동 정상 처리·알림은 하지 않는다.

## 공통 제약

- ID는 같은 관측 흐름을 구분할 뿐, 실제 사람이나 낙상의 증거가 아니다.
- ID 변경·모호한 연결·미배정 관측·관절 구성 변경·비정상 시간·입력 크기 변경·실패 프레임은 이력을 끊는다. 무관한 배경 미배정 관측도 보수적으로 끊는 기존 방침을 유지한다.
- 실제 depth가 있고 바닥 근접을 지지하지 않으면 RGB 형태만으로 뒤집지 않는다. 이 데이터에서는 depth 없음, 로봇 이동 unknown을 유지한다.
- 같은 클립의 같은 추적 ID에서 각 보조 규칙은 최대 한 번 근거를 추가한다. 전체 요청 병합은 기존 dedup을 사용한다. 운영용 재무장·사건 종료는 이 실험 범위가 아니다.
- 기존 요청 근거는 삭제하거나 덮어쓰지 않는다. 중복 요청을 줄여도 원문 근거는 update에 남긴다.

## 측정

전체 84개에서 낙상 25 / 낙상 의심 25 / 정상 34의 후보 발생 영상 수를 별도로 제시한다.
이는 영상 단위 요청 발생률이며 대상자 낙상 감지율이나 VLM 정확도가 아니다.
변경된 영상·요청 프레임·근거 프레임·정답 시작 구간 대비 최초 요청 시각을 모두 저장한다.
정답 박스가 그 프레임에 있을 때만 대상 대응을 채점하고, 중간 프레임의 정답이나 신원을 보간하지 않는다.
새로 발생한 요청은 실제 이미지로 확인한다. 처리 시간은 보조 판단 코드의 CPU 시간으로만 보고하며 영상 시각·실물 지연·VLM 응답 시간과 혼동하지 않는다.

기존 정상 10/34에서 추가되는 요청이 있으면 숨기지 않고 모두 검토한다. 기준 만족을 위해 이번 라벨이나 박스를 수정하지 않는다.

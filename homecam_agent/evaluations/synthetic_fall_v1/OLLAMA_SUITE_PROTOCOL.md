# Ollama 모델 비교 · 2026-09-10

모델별 결과를 보기 전에 고정한 비교 조건이다. 제품 코드는 변경하지 않는다.

## 대상

공식 Ollama Vision 목록과 이전에 공개된 주요 Vision 계열의 기본 크기별 태그를 확인한다.
같은 가중치의 별칭·여러 양자화 버전·모든 커뮤니티 파생 모델을 별개 모델로 세지 않는다.
작은 모델만 고르지 않고, 64GiB Mac에서 가능한 큰 모델도 포함한다.
가중치가 40GiB를 넘으면 macOS·영상 토큰·KV 캐시 여유 때문에 실행 대상에서 제외하고
목록에 사유를 남긴다. 이것은 Jetson에 탑재할 수 있다는 뜻이 아니다.
다운로드 실패, Vision 미지원, 입력 길이 미지원도 목록에서 숨기지 않는다.

클라우드는 사용자가 허용했으나 **무료 계정·잔액·추가 과금 여부를 확인하기 전에는
호출하지 않는다.** 유료 크레딧 구매·요금제 변경·자동 충전은 하지 않는다.
로컬 비교기는 원격 모델을 거부한다. 무료 클라우드가 확인되면 별도 실행 기록을 만든다.

## 두 가지 실제 호출

1. `full`: 41개 전체 영상에서 균등하게 RGB 12장을 뽑아 VLM을 실제 호출한다.
2. `gated`: 동일한 YOLO-Pose 가중치·트래커·후보·중복 요청 설정으로 **새로 추론**한다.
   후보가 생성되는 시점에 VLM을 실제 호출한다. 시작부터 후보 시점까지의 RGB에서
   최대 12장을 뽑고, 후보 이후 프레임은 전달하지 않는다. 후속 영상을 기다리는 시간은 0이다.
   후보가 없는 영상은 호출하지 않는다. 기존 VLM 결과를 골라 재사용하지 않는다.

gated에서 Pose 원문·후보·호출 시각을 저장한다. GT와 이전 출력은 후보 생성에 사용하지 않는다.
기존 고정 결과와 새 추론의 일치 여부는 호출 전에 검사한다. 임의 ID 접두사만 제외하며,
관절·박스·수치·후보 시각이 다르면 평가 조건이 바뀐 것이므로 중단한다.
영상 전체를 미리 본 full과 그 시점까지만 본 gated는 관측 범위가 다르다.

현재 비교는 RGB만으로 VLM을 비교한다. YOLO 후보는 호출을 결정하고 로그에 남지만
프롬프트에 낙상 판정·정답·파일명·ID·관절 요약을 넣지 않는다.
센서 요약을 함께 전달하는 방식은 이 결과와 섞지 않고 후속 실험으로 구분한다.

## 고정된 입력과 실행

- 동결된 합성 영상 41개, 사용자 검토 라벨 유지. 애매한 5개는 분류 정확도에서 제외.
- 640×400 원본, JPEG 품질 90. 박스/자막/크롭/해상도 변경 없음.
- 공통 한국어 지시문과 JSON Schema를 본문 및 `format`에 동일하게 전달.
- temperature=0, seed=0, num_predict=1200, num_ctx=16384.
- thinking 지원 모델은 `think=false`. 미지원 모델에는 필드를 보내지 않는다.
- 호출 300초 상한, 자동 재시도 없음. 출력 형식 오류는 결과로 보존하고 다음 영상 진행.
- 요청 자체 실패는 해당 모델을 중단하고 원인·완료된 결과를 남김. 실패 모델은 정확도 0으로
  바꾸지 않고 미완료로 표시한다. 복구 후 다시 시도하려면 별도 실행 폴더 사용.
- 모델은 한 번에 하나만 추론. 모델별 cold-load 시간과 응답 토큰·프롬프트 토큰을 저장.
- raw 응답을 검증 전에 저장, 파일별 SHA256·모델 digest·소스 해시 기록. 파일 0600.

## 채점

분류 정답: `observed_fall → confirmed_fall`, `found_down → found_down`,
`normal_activity → normal_activity`. 애매함은 분포만 제시한다.
주 지표에서는 형식·의미 검증도 통과해야 정답으로 인정한다. 오류는 분모에서 빼지 않는다.
원문 분류만 맞은 비율은 별도 보조 지표다.

- 전체 입력의 정확도: 명확한 36개 중 유효한 정답 수.
- YOLO 호출 후 정확도: 실제 호출된 명확한 영상 중 유효한 정답 수.
- 전체 경로 정확도: 명확한 36개 기준. 정상 영상 미호출은 시스템 음성으로 세지만,
  낙상/쓰러진 사람 미호출은 미탐으로 유지. 미호출을 VLM의 정상 답변으로 기록하지 않는다.
- 라벨별 분포·미호출·유효 오류, 요청~응답 시간 중앙값/p95, 영상별 원문.

이는 합성 개발 데이터 결과다. 실제 낙상 확률이나 안전성을 입증하지 않는다.
Pose는 Linux CPU, VLM은 Mac에서 실행한다. 영상 시각은 source timestamp, 추론 시간은
실제 측정값이다. 오프라인 순차 재생이므로 실시간 카메라·음성·주행 동시 실행 지연으로
주장하지 않는다. 로봇이 계속 촬영하는 동안의 큐·후속 질문·알림은 이번 검증에 포함되지 않는다.

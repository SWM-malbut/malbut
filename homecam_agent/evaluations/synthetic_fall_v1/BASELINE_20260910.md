# YOLO-Pose 낙상 후보: 현재 기준 측정

2026-09-10. **확인 대상 21개 중 12개에 신호가 나왔고, 9개는 영상 끝까지
신호가 없었다. 정상 영상 20개 중 3개에도 확인 신호가 나왔다.**

이 수치는 개발용 합성 영상에서 **VLM·질문으로 넘길 후보를 만들었는지**를
측정한 것이다. 낙상 확정률·보호자 오알림률·실물 로봇 성능이 아니다.

## 실행 범위

- 기존 41개 영상, 640×400 / 12fps. 총 길이 약 215초, 영상당 약 5.2초.
- YOLO26n-Pose ONNX, 입력 640×640 stretch, 신뢰도 0.10, 관절 0.50, 5Hz 샘플링.
- 실제 모델 추론 1,106프레임. 현재 `PersonPoseEstimator → PersonPoseTracker →
  FallCandidateDetector`를 직접 호출했다. ROS 콜백·주행·네트워크는 실행하지 않았다.
- depth·주행 정보 없음. `robot_motion=unknown`. 모델이나 후보 임계값을 수정하지 않았다.
- PC CPU, ONNX Runtime 1.23.2 / OpenCV 4.11.0 / NumPy 1.26.4.
  ORT intra/inter threads 2/1, OpenCV 1 thread.
- 시작 전에 `BASELINE_PROTOCOL.md`와 입력 해시를 고정했다. 기존 사용자 분류와
  검토한 박스·시간 범위를 사용했고, 누락 프레임의 박스는 보간하지 않았다.
- 출력 15건의 원본 RGB와 표시된 상자를 Codex가 직접 대조했다.
  **독립적인 사람 검수나 블라인드 평가는 아니다.**

## 다시 실행하기

저장소 루트에서 실행한다. `DATASET`은 원본 자료 경로, `MODEL`은 기존 ONNX,
`OUT`은 쓰기 가능한 평가 전용 폴더다. Python 3.10+, OpenCV, ONNX Runtime,
NumPy, Pillow가 필요하다. 하위 출력 폴더는 없어야 하며 기존 결과를 덮어쓰지 않는다.

```bash
LABEL=homecam_agent/evaluations/synthetic_fall_v1/spatial_temporal_draft.json
REPLAY=homecam_agent/scripts/replay_fall_baseline.py
SCORE=homecam_agent/scripts/score_fall_baseline.py
HASH=1d6045d98de0fb825c50fa29eb6d2323b1e03be0c666ddb5ecbe02dcd37a0dfa

python3 "$REPLAY" prepare --dataset "$DATASET" --annotations "$LABEL" --output "$OUT/frozen"
python3 "$REPLAY" run --dataset "$DATASET" --frozen "$OUT/frozen" --model "$MODEL" --model-sha256 "$HASH" --output "$OUT/run"
python3 "$SCORE" --frozen "$OUT/frozen" --run "$OUT/run" --output "$OUT/review" --render-dataset "$DATASET"
```

새 실행의 `review/audit_template.json`에 각 출력 대상 대조를 기록한 뒤
`--audit`을 주어 새 출력 폴더로 다시 채점한다. 후보 ID는 실행마다 달라지므로
기존 감사 파일을 새 실행에 재사용하지 않는다. 감사가 없으면 대상 연결은
`unknown`으로 남고 성공률도 가능한 범위만 출력한다. 이미 과거에 본 41개를
다시 돌렸으므로 이 결과로 일반화 성능을 주장하지 않는다.

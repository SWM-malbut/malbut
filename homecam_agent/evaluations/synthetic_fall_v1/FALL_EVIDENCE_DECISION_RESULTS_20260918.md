## 3. 형식 오류만 분리한 추가 진단 — 주 점수가 아님

실험 종료 후 원인을 구분하기 위해 원본은 그대로 두고 별도 진단을 했다. 추가 호출은 없다.

- 중복 키는 값이 JSON 기준으로 완전히 같을 때만 하나로 읽는다. 서로 다르면 거부한다.
- `additionalProperties`는 정확히 `false`일 때만 제거한다.
- `observations_count`는 실제 관찰 배열 길이와 같은 정수일 때만 제거한다.
- 다른 추가 필드나 판단 내용은 고치지 않는다. 라벨·근거도 수정하지 않는다.

이는 결과를 본 후 만든 진단이므로 원래 계약·채점 기준을 대체하지 않으며 운영 파서에도
적용하지 않는다. 특정 영상만 고른 것이 아니라 137개 응답 전체에 동일하게 적용했다.

| 형식 문제만 분리한 참고 비교 | 기존 | 새 프롬프트만 | 새 프롬프트 + 판정 조건 |
|---|---:|---:|---:|
| 단독 | 74/84 (88.1%) | 73/84 (86.9%) | 70/84 (83.3%) |
| 후보 후, 재확인 포함 | 45/52 (86.5%) | 44/52 (84.6%) | 43/52 (82.7%) |

형식 문제를 분리해도 이 실행에서 개선은 없었다. 특히 단독에서 낙상·의심을 정상으로
판정한 수는 여전히 2개에서 8개로 늘었다. 1개 차이의 정확도로 일반적인 우열을 확정할 수는
없지만, 이번 변경을 채택할 개선 근거는 없고 안전상 회귀가 관찰됐다.

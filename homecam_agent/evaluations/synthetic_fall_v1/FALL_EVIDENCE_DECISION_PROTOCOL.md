# VLM 관찰 근거 분리 비교 (2026-09-18)

실행 전에 고정한 개발 실험이다. 운영 배포나 독립 검증 세트가 아니다.

## 바꾸는 부분

기존 세 분류와 라벨·채점 기준은 유지한다. 출력에 관찰 사실(최대 4개), 그 사실을
볼 수 있는 입력 이미지 번호, 낙상 과정·몸의 제어 여부·자발적 행동의 가능성을 추가한다.
모델이 주장하는 사실이지 외부 센서로 검증한 사실은 아니다.

판단 규칙은 다음으로 고정한다.

- 낙상: 사람이 보이고, 과정과 제어 상실이 명확하며, 자발적 행동 해석이 남지
  않았다고 모델이 보고하고, 두 입력 이미지 이상의 구간에 구체적인 동작 근거가
  하나 이상 있어야 유지한다. 특정 동작이나 단서 개수를 일률적으로 요구하지 않는다.
- 빠른 속도·누운 자세만의 근거, 한 장에서 추정한 과정, 자발적 행동과 구분되지
  않는 경우는 낙상 의심으로 남긴다. 실제 프레임에서 근거가 맞는지는 별도 검토 대상이다.
- 모델이 정상이라고 답하면서 동시에 명확한 낙상 과정을 주장하는 경우도 의심으로
  남긴다. 정책이 모델의 정상·의심을 낙상으로 올리지는 않는다.
- 잘못된 JSON·범위 밖 이미지 번호·호출 실패는 정상도 의심도 아닌 미해결로 기록한다.
- 원본 모델 분류와 위 규칙 적용 분류를 따로 채점한다. 오류 사례 번호나 정답을
  보고 결과를 덮어쓰지 않는다. 결과 확인 뒤 임계값이나 프롬프트를 조정하지 않는다.

## 비교 입력

1. 직전 재확인 실험의 첫 확인 52 + 재확인 6 = 58개 입력 고정.
   이미지·시각·JPEG·최대 12장 추출 조건을 바꾸지 않는다. 미호출 32개는 미호출 유지.
   VLM 지연이 달라져도 이 실험에서는 호출 시점/영상 길이를 다시 선택하지 않는다.
2. VLM 단독: 같은 84개 전체 영상, 기존 단독 실행과 같은 이미지 입력.
3. 두 조건에서 요청 본문이 완전히 같으면 새 응답 1건을 공유하고 사용처를 모두 기록한다.
   비교 조건 수와 실제 API 호출 수를 구분한다.

Gemma Cloud 모델 메타데이터와 옵션(temperature=0, seed=0, num_predict=1200)을
유지한다. 기존 응답은 동결된 비교 대상으로 재사용하며 새 프롬프트 입력은 실제 호출한다.
Cloud의 실제 가중치 고정과 같은 입력의 완전한 재현성은 보장되지 않는다.
무료 계정만 허용하고 인증·결제·할당량 오류 시 전체를 중단한다. 자동 재시도 없음.

## 평가

- 기존 / 새 프롬프트 원본 분류 / 새 프롬프트 + 판단 규칙을 구분한다.
- strict JSON과 바깥 코드 블록만 제거한 보조 점수를 따로 낸다.
- 3분류 정확도, 낙상·의심 포착, 정상으로 잘못 내린 수, 의심→낙상 단정,
  정상 오경보, 미호출·실패, 실제 API 지연을 함께 기록한다.
- 413과 V024는 미리 지정한 확인 사례다. 두 개에만 유리한 결과로 전체 개선을 주장하지 않는다.
- 관측 문장이 틀리거나 불명확한데도 clear로 선언하는 문제는 이 규칙만으로 검증할 수 없다.
- 재확인 뒤 정상으로 바뀌어도 과거 실제 낙상 기록을 지우는 운영 정책을 구현하는 실험이 아니다.

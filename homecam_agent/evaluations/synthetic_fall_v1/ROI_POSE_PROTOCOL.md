# 인물 주변 재검출 실험 조건 — 2026-09-10

404·442의 기존 실패를 확인한 뒤 정한 개발 실험이다. 전체 41개 결과를 보기 전에
조건을 고정한다. 실물 성능/독립 평가로 주장하지 않는다.

## 바꾸는 것과 유지하는 것

전체 화면 YOLO26n-Pose(640×640 stretch, 후보 점수 0.10)는 그대로 실행한다.
이후 최근 인물 위치 주변에서 **같은 모델로 실제 추가 추론**한다.
원본 640×400, 5Hz 표본, 모델 바이트, 기존 추적/낙상 규칙/pose-loss/요청 묶기는 유지한다.
정답 박스·낙상 시각·영상 분류·파일 이름을 추가 추론 조건에 사용하지 않는다.

## 추가 추론 조건

1. 전체 화면 경로에서 같은 ID의 자세 계산 가능한 관측이 3회 연속 나오고,
   그때 검출 점수도 매번 0.45 이상일 때 최근 위치를 기억한다.
   이 기준은 **추가 연산의 시작 조건**일 뿐 기존 0.10 후보를 삭제하는 기준이 아니다.
2. 이후 전체 화면 경로에서 그 ID가 missing 또는 자세 계산 불가일 때 재검출한다.
   모호한 연결/미할당 Pose가 있는 프레임에서는 새 영역 추론을 보류한다.
3. 마지막 강한 연속 관측의 실제 시각부터 최대 **1.5초**, 표본마다 최대 한 번 시도한다.
   전체 화면의 유효한 관측만 위치와 시각을 갱신한다. 재검출 결과로 유효 시간을 늘리지 않는다.
   만료된 위치, 시간/해상도 변경은 폐기한다.
4. 여러 사람이면 한 프레임 최대 **2개 영역**을 처리한다. 오래 시도하지 않은 대상부터
   번갈아 고른다. 검출 인원을 1명으로 제한하지 않는다.
5. 최근 박스 폭 w, 높이 h에 대해 영역 폭은 max(3w, 2h, 96px),
   높이는 max(2h, 1.5w, 96px)로 한다. 중심은 박스 중심에서 아래로 0.25h 이동한다.
   실제 영상 경계에서 잘라 낸다. 가려진 관절/새 화소를 생성하거나 검은 패딩을 넣지 않는다.
6. 자른 영역을 같은 640×640 입력으로 추론하고, 박스와 관절을 원본 좌표로 정확히 되돌린다.
   영역 안의 모든 후보를 보존한다. 최근 ID를 새 박스에 강제로 붙이지 않는다.
7. 전체 화면 관측은 그대로 둔다. IoU 0.85 이상인 거의 같은 박스만 중복 처리한다.
   사람을 합치는 일반 NMS나 ‘점수가 가장 높은 사람 하나’ 선택은 하지 않는다.
8. 합친 관측으로 같은 추적/낙상 후보/관측 누락/요청 묶기 로직을 다시 실행한다.
   추가 관측 때문에 ID 연결·요청이 바뀔 수 있으므로 개선과 악화를 모두 기록한다.

## 비교와 무결성

- 같은 실행에서 전체 화면 추론을 새로 돌리고 저장된 원래 출력과 값 단위로 대조한다.
- 전체 화면 대조 경로의 최종 요청도 기존 요청 묶기 실행과 일치해야 한다.
- 재검출 추가 경로는 별도로 평가한다. 누락 프레임에 옛 Pose를 복사하지 않는다.
- 41개 모두 동일 조건. 404·442의 대상 회복뿐 아니라 정상 영상의 추가 후보/요청과
  다른 사람으로의 잘못된 연결을 사진으로 확인한다.
- 추가 영역 원시 출력 수는 사람 수/성공률이 아니다. 수동 대상 박스가 있는 프레임의
  대응, 실제 RGB 대상 확인, 확인 요청을 따로 기록한다.
- 전체 화면 추론 시간, 영역 추론 횟수·시간, 합산 처리 시간을 같은 PC에서 측정한다.
  공유한 전체 화면 추론은 두 경로 모두 한 번씩 계산한다. 디코딩·모델 로딩 시간은 제외한다.
- 화면에 보이는 사람 전체가 한 번도 강하게 잡히지 않으면 이 경로는 시작하지 못한다.
  이불 아래의 안 보이는 골반을 복원하는 방법도 아니다.

모델/규칙/제품 설정/ROS/AWS는 변경하지 않는다. VLM·음성·알림 호출과 커밋·배포는 없다.
결과를 확인한 뒤 임계값을 맞추지 않고, 실패 시 조건과 이유를 함께 남긴다.

이번 결과에서의 선택

개별 이미지 24개를 한 요청에 보내는 방식이 가장 유리했다. 선정 물체 명칭 27/35건, 약 12.59원으로 구분 강화 격자보다 약 2.81원 더 들었다.

6장 격자는 이름 25/35건을 찾았지만 좌표 68/111건이 해당 사진 밖으로 나가 저장 시 null이 됐다. SoM은 이름 5/35건에 그쳤고, F15의 바닥 영역을 냉장고로 설명하는 등 의미 오류가 많았다. 선택한 100개 번호가 모두 유효해도 물체를 맞게 가리킨다는 뜻은 아니다.

SoM의 CPU 분할·표시에 527.7초가 추가됐다. 각 방식 1회 결과이므로 기법 전체의 우열로 일반화하지 않는다. 운영 기본 입력 방식은 이번 실험에서 변경하지 않았다.

어떤 기법을 적용했나

  • IG-VLM: 영상에서 대표 6장을 뽑아 3×2 격자로 읽는 방식. 여기서는 사진을 버리지 않고 연속 6장씩 격자 4개를 한 요청에 넣었다. 사진당 480×300px, 격자 1528×864px. 사진 번호와 칸 범위, 사진별 JSON을 추가했으므로 논문 그대로의 재현은 아니다.
  • Set-of-Mark: 분할 모델이 영역을 만들고 번호를 붙여 VLM이 참조한다. 여기서는 SAM ViT-B 자동 마스크 → 중복 필터 → 최대 40개 윤곽·숫자 → LLM mark_id 선택 → 원본 bbox 복원. 원본 640×400px, 이미지 24개. 번호는 사진 안에서만 유효하다. SAM은 물체 이름을 제공하지 않는다.
  • OpenAI 영상 예제: 여러 프레임을 개별 input_image로 한 요청에 전달한다. 여기서는 원본 24장 전체를 각 F번호 메타데이터와 번갈아 입력했다. 예제 모델을 복제한 것이 아니라 비교 모델을 동일하게 유지했다.

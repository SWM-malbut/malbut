# 2026-09-12 한국어 STT 합성 음성 비교

같은 합성 음성 20개(총 43.798초)에서 OpenAI는 일반 문장 11개 중 10개를, 로컬 기본 설정은 9개를 공백·문장부호를 제외한 원문과 일치하게 인식했습니다. OpenAI의 본문 불일치 1개는 십오를 15로 표기한 차이입니다. 처리 시간 중앙값은 로컬 기본 0.657초, OpenAI 0.874초였습니다.

이름 힌트는 제이크야 단독 인식을 2/3에서 3/3으로 개선했지만, 무음에서도 힌트 문장을 출력했습니다. 호출어 감지 성공과 일반 STT 품질은 분리해서 평가해야 합니다. 아래 수치는 이 합성 음성·현재 Mac의 단회 측정 결과입니다.

OpenAI 호출은 20회 시도·20회 성공이며 추가 재호출은 없었습니다. 입력 해시·모델 파일·결과 누락 및 중복을 독립 검산했고, STT 회귀 시험은 94 passed, 1 skipped(ROS 미설치)였습니다.


로컬은 Whisper small / faster-whisper 1.2.1 / CPU int8 / 6 threads이며, OpenAI는 gpt-transcribe입니다. local_hint에는 “로봇 이름은 제이크입니다.”를 넣었습니다.

- Yuna 한 화자의 합성 음성 20개를 각 엔진에서 한 번씩 측정했습니다. 정답은 TTS 입력 문장입니다.
- 유한한 WAV의 끝을 알고 처리하며 VAD, 실시간 호출어 대기, 마이크·거리·로봇 소음은 평가하지 않습니다.
- 로컬 모델 로드와 워밍업은 시간에서 제외했고 API 시간에는 네트워크가 포함됩니다.
- local_base와 OpenAI가 본 비교이며 local_hint는 기존 이름 힌트 설정을 사용한 보조 결과입니다.
- CER는 NFC 변환 후 공백과 Unicode P 범주 문장부호를 제거합니다. 숫자 표현은 정규화하지 않아 십오→15 같은 표기 차이도 오류로 계산됩니다.
- CER는 성공한 항목만 집계하므로 평가 수와 예정 수를 함께 확인해야 합니다. 실패·미완료는 별도 표시합니다.
- 호출어 정답은 제이크야 단독 3개입니다. 문장 안의 제이크야는 이번 판정에서 비호출어로 처리합니다.

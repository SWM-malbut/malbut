# 3GB 음성 메모리 제약 내 동일 Small 비교

STT와 TTS를 합쳐 남은 3.xxGB 안에서 실행한다는 사용자 조건을 유지한다. 보수적인 실험 예산은 음성 기능 전체 3,000,000,000바이트이며 VAD, AEC, 버퍼, ROS 및 필요한 오디오 전송을 포함한다. 상주 ASR을 추가하거나 더 큰 모델을 적용하지 않는다.

같은 모델 크기의 한국어 학습 가중치 SungBeom/whisper-small-ko를 기존 Small과 로봇의 동일 whisper.cpp/CUDA/6스레드/greedy 설정으로 순차 비교했다. 정상 서비스를 멈춘 뒤 모델별 별도 프로세스를 종료하고 다음 모델을 시작했다. 저장 입력 57개씩 총 114회, 별도 준비 전사 2회. 과거 전사 기록이 있는 기존 모델 56개는 모두 그대로 재현됐다.

|입력|개수|기존 Small 전체 일치|한국어 Small 전체 일치|기존 CER|한국어 CER|
|---|---:|---:|---:|---:|---:|
|기존 실제 수음 녹음(사람·합성 음원 구분은 입력별 기록)|40|24|30|8.86%|3.20%|
|합성 원음 중단 명령|6|6|5|0.00%|12.00%|
|사람 원음|1|1|1|0.00%|0.00%|
|후보15 조용한 조건 USB 이후 ASR 입력|5|4|1|1.60%|3.20%|
|후보15 실제 겹침 ASR 입력|5|2|3|9.60%|2.40%|

문자 오류율과 문장 일치는 공백·문장부호만 제외했다. 숫자의 표기 차이를 정답으로 자동 치환하지 않았다. 기존 자료를 반복 사용한 진단이며 새로운 독립 검증 집합 성능으로 일반화하지 않는다.

판정: **미채택**. 기존 녹음의 평균 오류는 줄었으나 깨끗한 “멈춰”를 “맘치워”로 바꿨다. 새 조용한 수음 5개 중 4개에는 문장 앞에 잘못된 “3”을 붙였다. 새 겹침 입력은 3/5로 사전 기준 4/5에도 미달했다. 오류를 후처리로 삭제하거나 문장 정답을 힌트로 주지 않았다.

|메모리 근거|관측 추정 최고|범위|
|---|---:|---|
|이번 순차 ASR 비교|1,248,788,480바이트|ASR 단독 cgroup/PSS+nvmap 추정|
|최근 실제 겹침 후보16|2,110,130,176바이트|STT·Piper·VAD·AEC·버퍼·공유 오디오 포함 추정|

두 측정은 약 0.2초 간격의 관측 추정이며 중복 계산과 샘플 사이 피크 가능성이 있다. ASR 단독 수치를 STT+TTS 전체 합격 수치로 사용하지 않는다. CPU 및 전체 물리 시험 기준은 아직 미충족이다.

정상 interaction-20261028 서비스가 실행되고, 시험 서비스가 종료됐으며, 마이크 beam=-3/debug=0/mic6_circle/PGA30dB×6 복원을 새로 확인했다. 한국어 모델은 Mac에 해시 검증해 보존하고 로봇의 시험용 사본만 제거했다. 정상 서비스 모델은 기존 Small, TTS는 Piper 3스레드를 유지한다.

입력·정답·114개 전사·전사별 시간·출력 해시는 상세 점수, 시험 복원 근거는 복원 점검에 있다. 원본 결과는 work/small_ko_compare_results_v1, 메모리 표본은 work/small_ko_compare_results_v1_memory에 보존했다.

겹침 감지 뒤 정확한 전사와 대화 연결이라는 전체 목표는 아직 미완료다. 다음 수정도 3GB 예산 안에서 수음·앞부분 보존·잡음 분리의 실제 실패 증거를 기준으로 제한한다.

  `9c46b71e19436a8b46e5cb3acc2bc2d853f1ceca4a455ecb48361d360be34e1c`.

## 로컬 검증

Python3와 `pytest`, `numpy`가 있는 환경에서 저장소 루트에서 실행한다.

```sh
python3 tools/speech_overlap_20261029/check_checkpoint.py
python3 tools/speech_overlap_20261029/check_checkpoint.py --test
```

첫 명령은 소스·문서 해시와 집계를 검증한다. 두 번째 명령은 임시 디렉터리에
검증된135개 코드 파일을 조합해 선택한 오프라인 회귀 검사를 실행하고 제거한다.
저장소/로봇 설치본을 수정하거나 마이크·스피커를 열지 않는다.
이후 기준 저장소 파일이 달라지면 해시 검증이 실패하므로 이 체크포인트 커밋으로 확인한다.

## 별도 보관한 자료와 실제 재현 조건

원음·Mac 마이크 녹음·DB·전체 서비스 로그·모델·ADB 실행 바이너리·환경 파일은 Git에

SHA-256을 검증했다. `evidence/summary.json`의 상대 경로/해시는 그 로컬 원본을 가리킨다.
공개 요약만으로 원음까지 재검증할 수 있다는 뜻은 아니다.

로컬 보존 폴더 이름은 `interaction_upgrade_20261028_mac`이며, 시험 자료는
`work/live_runtime19_*`, Mac 녹음은 `work/runtime19_support/live_runtime19_*`,
전체 시험 도구는 `tools/`에 있다. 실제 음향 시험 재현에는 해당 보존본의 드라이버,
음원, ROS 환경과 `runtime19/required-local-assets.json`의 배치별 보정 자료가 필요하다.
보정 파일은 다른 방향에 일반화하지 않는다.

`runtime19/start.sh`와 supervisor는 당시 로봇의 절대 경로/장치에 묶인 보존 소스다.
독립 설치 도구가 아니며 이 체크포인트 검증 명령은 이들을 실행하지 않는다.
실제 시험을 재개할 때는 원본 supervisor의 잠금·atomic 설정 교체·실제 PGA/
mic6_circle 확인·finally 복원을 유지해야 한다. 미채택 live-code 패치를 사용하지 않는다.

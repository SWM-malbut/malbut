음성 대화 기록

사용자의 최종 STT 인식 문장과 로봇의 TTS 요청 문장을 보여줍니다. 최신 기록이 위에 표시되며 자동 갱신됩니다.

TTS 요청은 실제 재생 완료를 뜻하지 않습니다. 재생 상태는 별도 행이며, 선택 구간에서 같은 재생 ID의 요청을 찾으면 요청 문장을 함께 표시합니다. STT와 답변을 시간순으로 임의 짝짓지 않습니다. 수신 시각 기준이며 토픽 관측이 누락될 수 있습니다.

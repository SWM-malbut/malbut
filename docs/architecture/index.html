현재 경로

①–⑪은 닫힌 안전 문법, server authority, verifier-issued TrustedConfirmation과 semantic Room plan을 side-effect 없이 시험한다.

Simulation 경계

simulation_succeeded, simulated=true, viewer_live=false는 계약 시험 결과다. 실제 이동이나 live video를 뜻하지 않는다.

빨간 GAP

durable ledger, Nav2 adapter, Homecam/KVS callback과 대화 feedback이 실제 E2E 전에 필요하다.

이 Atlas는 2026-08-15 저장소 코드와 문서를 기준으로 만든 구조 모델이다. RUN은 프로덕션 배포 완료와 같은 뜻이 아니다. 실제 프로세스 상태는 ROS graph, AWS 관측, 실물 E2E 검증으로 별도 확인해야 한다.
